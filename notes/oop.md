# Object-Oriented Programming (OOP) Principles

Object-Oriented Programming (OOP) is based on four key principles:

## 1. Encapsulation  
- Bundles data (attributes) and methods (functions) into a single unit (class).  
- Restricts direct access to internal details to prevent unintended modifications.  
- Example: Using **private** variables with **getter/setter** methods.

## 2. Abstraction  
- Hides complex implementation details and exposes only the necessary functionality.  
- Example: A `Car` class provides a `drive()` method without exposing how the engine works.

## 3. Inheritance  
- Allows a child class to inherit properties and behaviors from a parent class.  
- Promotes code reuse and hierarchy.  
- Example: A `Dog` class inheriting from an `Animal` class.

## 4. Polymorphism  
- Enables objects to be treated as instances of their parent class while maintaining their own behavior.  
- Achieved through **method overloading** (same method name, different parameters) and **method overriding** (subclass redefines a method).  
- Example: A `Bird` class with a `makeSound()` method that is overridden in `Parrot` and `Crow` classes.
