1. Class names in UpperCamelCase
2. Function and variable names in lowerCamelCase
3. Constant and Enum names in SCREAMING_SNAKE_CASE
4. Member variables (properties) start with m\_
5. Static variable names start with s\_
6. Global variable names start with g\_
7. Access specifiers in a class go from most accessable to least accessable (public -> protected -> private)
8. Getters are just lowerCamelCase (e.g. name)
9. Setters are "set" + UpperCamelCase (e.g. setName)
10. In a constructor initializer list each variable has to be placed on a new line
11. Abstract class names has to start with A (e.g. AMyClass)
12. Interface class names has to start with I (e.g. IMyInterface)
