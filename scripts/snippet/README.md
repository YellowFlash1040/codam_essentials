In order to create a snippet from a function `do_something()` you need to:
- Create a file without an extension "do_something"
- Put the function inside the file
- Make sure that there is a new line in the end of file
- Run `./snippet.sh do_something` and get the result file
- Copy snippet to your snippets file and press `ctrl + I`
- Give this snippet a `prefix` value in order to actually use it
